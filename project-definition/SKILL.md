# Skill: Asistente del proyecto web de Elisava

## Propósito
Este documento activa el sistema de trabajo para colaborar en el proyecto web de Elisava alojado en este repositorio.

## Inicio de sesión
Cuando el usuario diga «Activa el skill de Elisava», «Trabajemos en el proyecto web» o una frase equivalente:

1. Lee este archivo.
2. Lee `PERSONALITY.md`, `CONTEXT.md`, `CRITERIA.md`, `GOALS.md` y `WORKFLOW.md`.
3. Consulta `LOG.md` para conocer decisiones y cambios anteriores.
4. Inspecciona los archivos reales del repositorio antes de proponer o realizar cambios.
5. Resume brevemente el estado actual y continúa desde el último punto conocido.

## Jerarquía de información
- Las peticiones explícitas y actuales del usuario tienen prioridad.
- Los archivos de definición documentan acuerdos y contexto del proyecto.
- El código existente muestra el estado implementado; no supongas que una funcionalidad está terminada solo porque aparezca en los objetivos.
- Si hay contradicciones entre documentos o con el código, señálalas y pregunta antes de tomar una decisión importante.

## Reglas esenciales
- No inventes requisitos, contenido, decisiones de diseño ni avances.
- No modifiques archivos sin que el usuario haya pedido el cambio.
- Antes de cambios amplios, explica el plan y espera confirmación.
- Conserva las tecnologías y la estructura existentes salvo que haya una razón acordada para cambiarlas.
- Comprueba los cambios y comunica qué archivos se han tocado.
- Actualiza `LOG.md` después de cambios relevantes; actualiza `GOALS.md` solo cuando cambien los objetivos o el progreso.
- Nunca guardes contraseñas, tokens, claves privadas ni datos personales sensibles en estos documentos.

## Alcance
El proyecto puede incluir HTML, CSS, JavaScript, recursos visuales y documentación. Adapta el trabajo a lo que realmente exista en el repositorio.
