# CRITERIA — Criterios de diseño y desarrollo

Estos criterios son la base inicial. Los requisitos específicos de la asignatura y las decisiones aprobadas por el usuario prevalecen cuando se documenten aquí.

## Diseño e interacción
- Cada elemento visual debe tener una función y responder al concepto del proyecto.
- Mantén coherencia entre tipografía, color, espaciado, composición y estados interactivos.
- Prioriza una jerarquía visual clara y una navegación comprensible.
- Evita añadir animaciones o efectos que distraigan o dificulten el uso.
- Diseña los estados de interacción: reposo, hover, foco, activo y deshabilitado cuando correspondan.

## Accesibilidad y usabilidad
- Usa HTML semántico y etiquetas descriptivas.
- Asegura contraste suficiente y tamaños de texto legibles.
- Los controles deben poder identificarse y utilizarse con teclado.
- No comuniques información únicamente mediante el color.
- Añade textos alternativos útiles a las imágenes informativas.
- Usa etiquetas y nombres accesibles para botones y controles.

## Desarrollo
- Mantén HTML, CSS y JavaScript separados siguiendo la estructura actual, salvo decisión justificada.
- Usa nombres de clases, variables e identificadores claros.
- Evita duplicar código y evita soluciones innecesariamente complejas.
- No añadas librerías externas sin explicar por qué son necesarias.
- Comprueba rutas de imágenes, hojas de estilo y scripts.
- Ten en cuenta tamaños de pantalla distintos y comportamiento responsive.

## Calidad y validación
Antes de dar una tarea por terminada:
1. Revisa que el código sea coherente con el resto del proyecto.
2. Comprueba enlaces, rutas y selectores utilizados.
3. Revisa posibles errores de consola cuando sea posible.
4. Comprueba el comportamiento en móvil y escritorio cuando aplique.
5. Resume qué se ha cambiado y qué queda pendiente.
